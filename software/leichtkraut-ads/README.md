# Leichtkraut Ads-Agent

Der halb-autonome Ad-Production-Agent (FORMAT × STYLE × SCRIPT → getimte, selbst-verifizierte 9:16-Ad). Diese Karte zeigt sein **Innenleben**: wo die KI entscheidet, welches Wissen (Skills) sie liest, welche Tools sie anruft, wo du als Mensch-Gate sitzt.

Der Live-Status pro Schritt (fertig / läuft / offen) wird aus den **echten Artefakten** eines Laufs berechnet — nicht behauptet. Ein Knoten ist erst grün, wenn sein Ergebnis auf der Platte liegt und seinen eigenen Gate besteht.

> Stand: LKAP Meilenstein 1 — die Karte steht (Struktur). Die Artefakt-Färbung (grün/coral/grau) kommt in M2.
